## 📋 Divisão de Tarefas e Ações a Serem Feitas

Para manter o projeto organizado, dividimos as ações nas seguintes fases. Cada membro pode assumir (ou ajudar em) partes específicas:

### 📍 Fase 1: Planejamento e Configuração Base
- [ ] Criar o repositório e convidar os 7 colaboradores (Feito!).
- [ ] Definir o tema exato e as funcionalidades do site.
- [ ] Fazer um rascunho (wireframe) de como será o visual das telas.
- [ ] Criar a estrutura inicial de pastas no repositório (ex: pastas para `img`, `css`, `js`).

### 📍 Fase 2: Estruturação (HTML)
- [ ] Criar o arquivo `index.html` principal.
- [ ] Estruturar o cabeçalho (Header/Nav) e o rodapé (Footer).
- [ ] Montar a estrutura de conteúdo (Main/Sections) usando tags semânticas.
- [ ] Criar os formulários necessários (se houver).

### 📍 Fase 3: Estilização e Design (CSS)
- [ ] Criar o arquivo `style.css` e linkar no HTML.
- [ ] Definir a paleta de cores e as fontes do projeto.
- [ ] Aplicar o layout base (ex: usando Flexbox ou Grid).
- [ ] Criar efeitos visuais (ex: hover em botões, background effects).
- [ ] Garantir que o site seja responsivo (fazer os Media Queries para celulares e tablets).

### 📍 Fase 4: Lógica e Interatividade (JavaScript)
- [ ] Criar o arquivo `script.js` e linkar no HTML.
- [ ] Fazer a validação de formulários (se houver).
- [ ] Criar funções de interatividade (ex: menus que abrem e fecham, cálculos, manipulação do DOM).

### 📍 Fase 5: Revisão e Entrega
- [ ] Juntar todas as partes do código.
- [ ] Testar o site no navegador para buscar bugs ou erros de layout.
- [ ] Corrigir caminhos de imagens e links quebrados.
- [ ] Fazer o commit final e enviar para o GitHub.
